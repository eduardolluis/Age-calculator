# Age Calculator

A small web application that calculates a user's age from a provided birth date.

## Highlights

- Date-based age calculation
- Interactive form behavior
- Responsive interface
- Client-side JavaScript logic

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Run Locally

```bash
git clone https://github.com/eduardolluis/Age-calculator.git
cd Age-calculator
```

Open `index.html` in your browser.
